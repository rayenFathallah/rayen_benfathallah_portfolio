            01
            

              
Rosenberger · 2026

              
Multi-agent engineering validation system

            

            In production
          

          

            

              
Problem

              

                Engineering work depends on documents, 3D models and standards all agreeing with each other. Checking
                that by hand is slow, repetitive and easy to get wrong, especially when one part has to satisfy
                several standards at once.
              

              
System

              
    
                
  • Orchestrator agent breaks each request into tasks and sends them to specialized agents.
    • 
                
  • Document validation agents check several engineering documents for completeness and consistency, in parallel.
    • 
                
  • Standards agents extract requirements from multiple standards into structured rules, then check deliverables against them.
    • 
                
  • 3D model agent proposes and applies adjustments to 3D models when a check finds a mismatch with a requirement.
    • 
                
  • Every decision is traceable, and engineers sign off at each step (human-in-the-loop).
    •

How I work

      
Problem to production.

      
    
        
  1. 
          01
          
    Frame
    
          
    Start from the decision the business needs to make, not from the model. Agree on what success means with the people who will use it.
    
        
    2. 
        
  2. 
          02
          
    Data
    
          
    Source, clean and validate the data. Build pipelines with data-quality checks so bad inputs are caught early.
    
        
    3. 
        
  3. 
          03
          
    Model
    
          
    Start with the simplest thing that could work, whether that's an ML model, an agent or an optimizer. Measure it against cost, latency and quality.
    
        
    4. 
        
  4. 
          04
          
    Ship & watch
    
          
    Deploy, monitor, detect drift and retrain. A model is finished when it keeps working without me checking on it.
